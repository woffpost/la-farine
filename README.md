# La Farine — Artisan Bakery

A rustic, story-driven landing page for an artisan bakery. Tabbed product showcase, custom order flow, and sourdough craft story — everything a neighbourhood bakery needs online.

## Features

- **Product tabs** — breads, pastries, celebration cakes — tab UI with item cards
- **Custom order flow** — name, date needed, product type, notes → order confirmed
- **Sourdough story** — craft narrative with process photos
- **Weekly specials** — rotating highlight section
- **Opening hours** — daily schedule with holiday note
- **Location & contact** — address, map placeholder, phone
- **Mobile navigation** — hamburger menu

## Tech Stack

- [Next.js 16](https://nextjs.org/) — App Router
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) — icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
